信息论——信息速率失真函数与熵压缩编码（一）

Posted on 2019-01-08 Edited on 2026-09-01 In 信息论

之前我们研究的问题，冗余度压缩编码以及信道编码（增加信息冗余度，以对抗信道中的传输错误），目的都是对信息进行可靠无差错的传输，信息熵没有变化，也就是是保熵的。之后的内容，我们不再保证信息传输是无差错的。
在实际中，很多情况下我们是没有必要把信息的所有内容都保留下来的。比如看视频的时候，有高清标清的选择，对应于不同的网络情况。同样的还有图片的有损压缩等等。

连续随机变量的量化

考察随机变量X∼N(0,σ2)X \sim N(0,\sigma^2)，如果对该随机变量进行无失真编码是不可能的，假如我们需要用RR比特来表示XX。所以被表示的结果X̂\hat X相对于原来的XX一定是有失真的。而这个失真如何度量呢？最简单的方法是采用平方误差度量最小化： E(x−X̂(x))2=∫−∞∞(x−X̂(x))2p(x)dx. E(x - \hat X(x))^2 = \int_ {-\infty}^{\infty} (x - \hat X(x))^2 p(x)dx. 现在假设R=1R=1，比较显然的是该符号应该代表X的正负。为了最小化误差，恢复值应该为其代表区域的条件平均： X̂(x)={2πσx̂=1(x≥0)−2πσx̂=0(x<0) \hat X(x) = \left \{ \begin{matrix} \sqrt{\frac{2}{\pi} }\sigma &\hat x = 1(x\ge 0)\\ -\sqrt{\frac{2}{\pi} }\sigma & \hat x=0(x < 0) \end{matrix} \right . 这个值是如何求得的？
首先我们要理解上面话的意思，最小化误差，其实也就是X的期望。对于整个分布来说，XX的期望当然是0，现在我们只看左侧，希望能得到左侧的条件分布X的期望是多少。 E(X)=∫−∞0xf(x)dx=∫−∞02σ2⋅1σ2πexp(−x22σ2)f(x)dx22σ2=−2σ2πexp(−x22σ2)|−∞0=−2σ2π=−2πσ \begin{aligned} E(X) &= \int_ {-\infty}^0 xf(x)dx\\ &=\int_ {-\infty}^0 2\sigma^2\cdot\frac{1}{\sigma \sqrt{2\pi} }exp(-\frac{x^2}{2\sigma^2}) f(x) d\frac{x^2}{2\sigma^2}\\ &= -\frac{2\sigma}{\sqrt{2\pi} } exp (-\frac{x^2}{2\sigma^2})|_ {-\infty}^{0}\\ &=-\frac{2\sigma}{\sqrt{2\pi} } = -\sqrt{\frac{2}{\pi} }\sigma \end{aligned} 如果R>1R > 1，又如何划分量化区间？如何选取这个2R2^R个X̂(x)\hat X(x)的取值？这个问题就没有上面那么简单了。

针对随机变量的最优（最小失真）量化准则：

  • 如果给定了一组X̂(x)\hat X(x)，那么将随机变量xx映射到最近的X̂(x)\hat X(x)可以最小化量化失真。由这种映射形成的划分称为Voronoi（Dirichlet）划分。
  • X̂(x)\hat X(x)的选取可以最小化对应趋于中的条件预期失真。

率失真理论的基本概念

失真度量（失真函数）是这样一个映射： d:X×X̂→R+ d:X \times \hat X \rightarrow R^{+} 它将源字母-恢复字母对映射到一个非负的实数，来代表失真多少。当原始字母集与映射的字母集是离散的，可以用一个矩阵来表示失真的大小，而在连续的情况下，这就是一个函数。失真函数永远都是非负的，因为我们没有办法说一个失真是负的。如果失真是有限的，则函数为有界函数。

下面举两个失真度量的例子：

  • 离散对称信源，信道输入输出及失真函数为： $$X = {x_1,...,x_k}\\ \hat X = { x_1 ,...,\ x_k}\\ d(x_i,x_j) = \left \{\begin{matrix} 0 & i=j\\ 1 & i \ne j \end{matrix} \right.$$

当恢复符号与发送符号对应时，失真不存在，不对应时，失真为1。这个失真被称为汉明失真。汉明距离在ORB特征匹配中是非常有用的。该失真矩阵为： [d]=[01⋯110⋯1⋮⋮⋱⋮11⋯0] [d] = \begin{bmatrix} 0&1&\cdots&1\\ 1&0&\cdots&1\\ \vdots&\vdots&\ddots&\vdots\\ 1&1&\cdots&0 \end{bmatrix} * 连续信源，平方失真度量：d(x,x̂)=(x−x̂)2d(x,\hat x) = (x - \hat x)^2
在语音编码中，常用的失真度量为：Itakura-Saito距离。而在图像处理中，目前还没有统一的失真度量，常用的还是平方失真度量。

因此，失真度量的选择要与实际结合。

平均失真

失真函数在输入输出联合空间中取统计平均为 D≜∑xi,x̂jp(xi)q(x̂j|xi)d(xi,x̂j)≜E[d(X,X̂)] D \triangleq \sum_ {x_i,\hat x_j} p(x_i)q(\hat x_j | x_i)d(x_i,\hat x_j) \triangleq E[d(X,\hat X)] 在给定信源分布与转移概率分布时，上式为信道传输失真总体的平均度量。

现在我们想做的事情如下图，XX经过信道之后，得到X̂\hat X，我们希望I(X;X̂)I(X;\hat X)尽可能小，以此来压缩比特的传输。当然，这个互信息是不能为0的，那一切就失去了意义。压缩下有个前提，就是对失真函数的约束。

率失真函数

针对信源XX和失真度量d(x,x̂)d(x,\hat x)，信息的率失真函数R(I)(D)R^{(I)}(D)定义为： R(I)(D)=minq(x̂|x):∑x,x̂p(x)q(x̂|x)d(x,x̂)≤DI(X;X̂) R^{(I)}(D) = \min_ {q(\hat x|x):\sum_ {x,\hat x} p(x)q(\hat x|x )d(x,\hat x) \leq D} I(X;\hat X) 这就是信息论意义下的率失真函数的定义，而RR的上标(I)(I)标识了这一点。

注：我们无法操作信源，能做的是最小化针对所有可能的条件分布q(x̂|x)q(\hat x | x)，并且使得联合分布满足要求的失真约束。这个函数求得的最小值，并不一定是可操作得到的，只是数学上的一个最小值。

率失真编码

率失真编码(2nR,n)(2^{nR},n)包括一个编码函数 fn:Xn→{1,2,...,2nR} f_n:X^n \rightarrow \{1,2,...,2^{nR} \} 一个解码函数： gn:{1,2,...,2nR}→Xn g_n:\{1,2,...,2^{nR} \} \rightarrow X^n 以及一个与(2nR,n)(2^{nR},n)相关的失真： E[d(Xn,gn(fn(Xn)))]=∑xnp(xn)d(xn,gn(fn(xn))) E[d(X^n,g_n(f_n(X^n)))] = \sum_ {x^n} p(x^n)d(x^n,g_n(f_n(x^n))) 注：

  • gn(1),gn(2),…,gn(2nR)g_n(1),g_n(2),…,g_n(2^{nR})构成了一个码本，以X̂n(1),…,X̂n(2nR)\hat X^n(1),…,\hat X^n(2^{nR})表示

  • fn−1(1),…,fn−1(2nR)f^{-1}_n(1),…,f^{-1}_n(2^{nR})，也就是f的反函数为对应的量化区间。

率失真区域

如果存在一组率失真编码(2nR,n)(2^{nR},n)，使得lim⁡n→∞E[d(Xn,gn(fn(Xn)))]≤D\lim_ {n \rightarrow \infty} E[d(X^n,g_n(f_n(X^n)))] \leq D，则称率失真对(R,D)(R,D)是可达的。

信源的率失真区域是对所有可行率失真对(R,D)(R,D)的闭包。

给定失真度量约束DD，率失真函数R(D)R(D)是速率RR跑遍率失真区域获得的下确界。

这个率失真函数是实际可以实现的。而香农告诉我们（香农第三定理），这两个率失真函数的值是相等的。

率失真定理（香农第三定理）

给定具有独立同分布p(x)p(x)的信源X和有界的失真度量d(x,x̂)d(x,\hat x)，率失真函数等于信息的率失真函数，即： R(D)=R(I)(D)=minq(x̂|x):∑x,x̂p(x)q(x̂|x)d(x,x̂)≤DI(X;X̂) R(D) = R^{(I)}(D) = \min_ {q(\hat x|x):\sum_ {x,\hat x} p(x)q(\hat x|x )d(x,\hat x) \leq D} I(X;\hat X) 是在失真约束DD下可以获得的最小信息传输速率。
