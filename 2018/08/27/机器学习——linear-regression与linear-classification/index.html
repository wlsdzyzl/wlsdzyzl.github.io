机器学习——linear regression与linear classification

Posted on 2018-08-27 Edited on 2026-09-01 In 机器学习

上一篇博客介绍了线性回归模型，但是不知道大家是否有这样的感觉：它与之前的PLA算法似乎有很多类似之处。 这两个算法都在使用线性的方法，也就是它们都是通过yn=WTXny_n = W^TX_n来计算出yny_n，只不过PLA算法通过yny_n来判断第n个样本的分类，而线性回归直接使用yny_n来作为它的预测值。

线性回归中，yy的值的范围是整个实数，从另一方面想，线性classification的yy取值只有+1，-1两个取值，这两个值当然也是实数，我们是否能将线性回归算法用作于线性分类中呢？

要思考这个问题，首先要决定如何将线性回归用于线性分类：对样本集{Xn,Yn}\{X_n,Y_n\}利用线性回归来进行学习，得到WW，然后通过sign(yn′)sign(y'_n)（其中yn′=WTXny'_n = W^TX_n）来对该样本进行分类。与PLA的区别是PLA一直在尝试各种不同的WW，而线性回归直接得到一个自己认为最好的WW。但是实际上它们的Hypothesis都是一样的。

这个算法是否可行，需要来检查它的泛化能力，也就是它的EoutE_ {out}是否像PLA算法一样有个上界。首先，我们观察两个算法对于错误的衡量有什么区别（注：以下错误都是单个样本的错误）：

category EinE_ {in}
linear classification(PLA) y≠y′y \neq y'
linear regression (y−y′)2(y - y')^2
linear regression to classification y≠sign(y′)y \neq sign(y')

在上面的表格中，我加了一行，也就是利用线性回归算法来进行线性分类时候的EinE_ {in}，这意味着它们的y′y'是一样的(实际上y′y'代表的应该是最终的预测值，这里正确的写法应该是h(X)h(X),此处只为了方便区分PLA)。

如果画出y = -1 与 y = +1 时候的曲线图，我们可以清晰地观察到，线性回归得到的错误永远是大于利用线性回归进行分类的错误的：

而通过之前vc bound那一节我们可以知道：

Eout≤Ein(classification)+...E_ {out} \leq E_ {in}(classification)+\sqrt {...}

也就可以得到：

Eout≤Ein(regression)+...E_ {out} \leq E_ {in}(regression) +\sqrt {...}

这意味着，只要linear regression的EinE_ {in}做的足够好，那么使用线性回归来做线性分类，往往也能取到比较好的效果。

实际中，我们也可以使用线性回归与PLA算法结合，先通过线性回归得到W，然后因为给了PLA或者POCKET算法一个好的初始点，它能更快得到最后好的结果。
