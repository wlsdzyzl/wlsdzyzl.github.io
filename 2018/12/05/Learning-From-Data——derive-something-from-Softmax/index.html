Learning From Data——derive something from Softmax

Posted on 2018-12-05 Edited on 2026-09-01 In 数据学习课程

这周的数据学习课更不知道该起什么题目了。主要是加上一些假设，从Softmax函数开始推导，最后得到一个非常简单的形式，从而大大简化了算法。这次的derivation和上篇讲得东西还是有一些相关的。 ## Review ##

首先回顾一下上篇博客介绍的内容，从HGR maximal correlation开始推导。依然是离散变量XX与YY。不过稍微做点拓展，我们在提取ｘ，ｙ的信息时，把他们映射到一个ｋ维度的向量，也就是： f(x)→ℝk,g(x)→ℝk.f(x) \rightarrow \mathbb{R}^k,g(x) \rightarrow \mathbb{R}^k.

这时候，和之前一样，做一些推导吧。这时候的相关系数变成了相关矩阵： max⁡ρXY=max⁡𝔼pXY[f(x)g(y)T] \max ρ_ {XY}=\max 𝔼 p_ {XY}[f(x) g(y)^T]

我们的约束变成： $$ \mathbb{E}[f (x)] = \mathbb{E}[ g(y)] = \mathbf{0}\\ \mathbb{E}[ f^2(x)] = \mathbb{E}[ g^2(y)] = I_ {k \times k} $$

问题描述变为： max⁡ΨTBΦ,s.t.⟨PX,Φ⟩=⟨PY,Ψ⟩=𝟎;ΦTΦ=ΨTΨ=Ik×k. \begin{aligned} \max \Psi^T B \Phi,s.t. &\langle\sqrt{P_X},\Phi\rangle = \langle\sqrt{P_Y},\Psi\rangle = \mathbf{0};\\ &\Phi^T \Phi = \Psi^T \Psi = I_ {k \times k}. \end{aligned}

其中： $$ \Phi = \begin{bmatrix} \phi(x_1),\phi(x_2),...,\phi(x_ {|X|}) \end{bmatrix}^T_ {|X|\times k},\\ \Psi = \begin{bmatrix} \psi(y_1),\psi(y_2),...,\psi(y_ {|Y|}) \end{bmatrix}^T_ {|Y|\times k},\\ B_ {y,x} = \frac{p_ {XY}(x,y)}{\sqrt{p_X(x)p_Y(y)} },B_ {|Y| \times |X|}. $$

而这时候的Φ\Phi与Ψ\Psi实际上是由Ｂ的第2，...,k+12，...,k+1右左特征向量组成: $$ \Phi = \begin{bmatrix} \upsilon_2,...,\upsilon_ {k+1} \end{bmatrix}\\ \Psi = \begin{bmatrix} \mu_2,...,\mu_ {k+1} \end{bmatrix} $$

f(x)=ϕ(x)pX(x),g(y)=ψ(y)pY(y)f(x)=\frac{\phi(x)}{\sqrt{p_X(x)} } ,g(y) = \frac{\psi(y)}{\sqrt{p_Y(y)} }.

HGR & Softmax

假设X,YX,Y是离散的，并且几乎独立(weakly dependent),也就是pXY(xy)−pX(x)pY(y)p_ {XY}(xy) - p_ {X}(x)p_ {Y}(y)非常小。

还记得softmax function: QY|X(y|X)=eXTWy+by)∑y′∈𝒴eXTWy′+by′ Q_ {Y|X}(y|X) = \frac{e^{X^TW_y + b_y)} }{\sum_ {y' \in \mathcal{Y} } e^{X^TW_ {y'}+b_ {y'} } }

在这里，我们把X,YX,Y再次进行信息提取，分布为f(X),g(Y)f(X),g(Y). 由于WyW_y与Y值相关，我们可以将WyW_y看作是g(y)。因此写成更通用的形式： QY|X(y|x)=efT(x)g(y)+b(y)∑y′∈𝒴efT(x)g(y′)+b(y′)=pY(y)efT(x)g(y)+b(y)−log⁡pY(y)∑y′∈𝒴pY(y′)efT(x)g(y′)+b(y′)−log⁡pY(y) \begin{aligned} Q_ {Y|X}(y|x) &= \frac{e^{f^T(x)g(y) + b(y)} }{\sum_ {y' \in \mathcal{Y} }e^{f^T(x)g(y')+b(y')} }\\ &= \frac{p_Y(y)e^{f^T(x)g(y) + b(y) - \log p_Y(y)} }{\sum_ {y' \in \mathcal{Y} }p_Y(y')e^{f^T(x)g(y')+b(y') - \log p_Y(y)} } \end{aligned}

现在我们定义：d(y)≜b(y)−log⁡pY(y)d(y) \triangleq b(y)-\log p_Y(y)，则： QY|X(y|x)=pY(y)efT(x)g(y)+d(y)∑y′∈𝒴pY(y′)efT(x)g(y′)+d(y′) Q_ {Y|X}(y|x) = \frac{p_Y(y)e^{f^T(x)g(y) + d(y)} }{\sum_ {y' \in \mathcal{Y} } p_Y(y')e^{f^T(x)g(y')+d(y')} } 可以看到，如果f=g=d=0f = g = d = 0，QY|X(y|x)=pY(y)Q_ {Y|X}(y|x) = p_Y(y).

由于我们的假设可以知道,pY(y)≈QY|X(y|x)p_Y(y) \approx Q_ {Y|X}(y|x)，则fT(x)g(y)+d(y)≈0f^T(x)g(y)+ d(y) \approx 0,根据泰勒展开: efT(x)g(y)+d(y)≈1+fT(x)g(y)+d(y) \begin{align} e^{f^T(x)g(y) + d(y)} \approx 1 + f^T(x)g(y)+ d(y) \end{align}

而: ∑y′∈𝒴pY(y′)efT(x)g(y′)+d(y′)≈∑y′∈𝒴pY(y′)[1+fT(x)g(y′)+d(y′)]=1+fT(x)∑y′∈𝒴pY(y′)g(y′)+∑y′∈𝒴pY(y′)d(y′)=1+fT(x)𝔼Y[g(Y)]+𝔼Y[d(Y)] \begin{aligned} \sum_ {y' \in \mathcal{Y} } p_Y(y')e^{f^T(x)g(y')+d(y')} &\approx \sum_ {y' \in \mathcal{Y} } p_Y(y')[ 1+f^T(x)g(y')+d(y')]\\ &= 1 + f^T(x)\sum_ {y' \in \mathcal Y} p_Y(y')g(y') + \sum_ {y' \in \mathcal Y}p_Y(y')d(y')\\ &= 1 +f^T(x)\mathbb{E}_Y[g(Y) ] + \mathbb{E}_Y[d(Y) ] \end{aligned} 而由泰勒展开11+x≈1−x\frac{1}{1+x} \approx 1-x得到： 1∑y′∈𝒴pY(y′)efT(x)g(y′)+d(y′)≈1−fT(x)𝔼Y[g(Y)]−𝔼Y[d(Y)] \begin{align} \frac{1}{\sum_ { y'\in \mathcal{Y} } p_Y(y' )e^{f^T(x)g(y' )+d(y' )} } \approx 1 -f^T(x)\mathbb{E}_Y[g(Y )] -\mathbb{E}_Y[d(Y )] \end{align} 结合上面的(1),(2)，我们得到： QY|X(y|x)=pY(y)efT(x)g(y)+d(y)∑y′∈𝒴pY(y′)efT(x)g(y′)+d(y′)≈pY(y)(1+fT(x)g(y)+d(y))(1−fT(x)𝔼Y[g(Y)]−𝔼Y[d(Y)])≈pY(y)[1+fT(x)g(y)+d(y)−fT(x)𝔼Y[g(Y)]−𝔼Y[d(Y)]]=pY(y)[1+fT(x)(g(y)−𝔼Y[g(Y)])+(d(y)−𝔼Y[d(Y)])] \begin{aligned} Q_ {Y|X}(y|x) &= \frac{p_Y(y)e^{f^T(x)g(y) + d(y)} }{\sum_ {y' \in \mathcal{Y} } p_Y(y')e^{f^T(x)g(y')+d(y')} }\\ &\approx p_Y(y)(1 + f^T(x)g(y)+ d(y) )( 1 -f^T(x)\mathbb{E}_Y[g(Y )] -\mathbb{E}_Y[d(Y )])\\ & \approx p_Y(y)[1 + f^T(x)g(y) +d(y) - f^T(x)\mathbb{E}_Y[g(Y) ] - \mathbb{E}_Y[d(Y) ]]\\ &= p_Y(y)[1+f^T(x)(g(y)-\mathbb{E}_Y[g(Y) ]) + (d(y) - \mathbb{E}_Y[d(Y) ])] \end{aligned}

现在我们令g̃(y)=g(y)−𝔼Y[g(Y)]，s.t.𝔼Y[g̃(Y)]=0\tilde{g}(y) = g(y) - \mathbb{E}_Y[g(Y)]，s.t. \mathbb{E}_Y[\tilde {g}(Y)] = 0.得到： QY|X(y|x)=pY(y)[1+fT(x)g̃(y)+d̃(y)] Q_ {Y|X}(y|x) = p_Y(y)[1+ f^T(x)\tilde g (y) + \tilde d (y)]

现在我们利用这个式子构建empiricalriskempirical risk，实际上也就是−1n∑i=1nlog⁡QY|X(yi|xi)-\frac{1}{n} \sum_ {i=1}^n \log Q_ {Y|X}(y_i|x_i).最小化经验风险(empirical risk)实际上也就是最大化𝔼pXY[QY|X(y|x)]\mathbb{E}_ {p_ {XY} } [ Q_ {Y|X}(y|x)]，也是极大似然估计。 log⁡QY|X(y|x)=log⁡pY(y)+log⁡(1+fT(x)g̃(y)+d̃(y))≈log⁡pY(y)+fT(x)g̃(y)+d̃(y)−12[(fT(x)g̃(y))2+d2̃(y)+2fT(x)g̃(y)d̃(y)] \begin{aligned} \log Q_ {Y|X}(y|x) &= \log p_Y(y) + \log (1+ f^T(x)\tilde{g}(y) + \tilde{d} (y))\\ & \approx \log p_Y(y) + f^T(x)\tilde{g}(y) + \tilde{d}(y) - \frac{1}{2} [(f^T(x)\tilde{g}(y))^2 + \tilde{d^2}(y) + 2 f^T(x)\tilde{g}(y)\tilde{d}(y)] \end{aligned} 上述过程用到了泰勒展开：log⁡(1+x)≈x−x22\log(1+x) \approx x - \frac{x^2}{2}.

$[Q_ {Y|X}(Y|X)] = [p_Y(Y)] + [f^T(X)(Y) ] + [(Y) ] - [ [(fT(X)(Y))2 + (Y) + 2 f^T(X)(Y)(Y)]] $

现在，我们来说明一些必要的东西：由假设得到pXY(x,y)−pX(x)pY(y)=ϵ⋅▫=o(ϵ)p_ {XY}(x,y) - p_X(x)p_Y(y) = \epsilon \cdot \square = o(\epsilon)，o(ϵ)o(\epsilon)表示ϵ\epsilon的无穷小量（这么说其实不准确，因为我们最后要最大化这种无穷小量，显然不合理，可以当作为衡量有多小的量级）。

因为QY|X(y|x)=PY(y)[1+fT(x)g̃(y)+d̃(y)]≈pY,Q_ {Y|X}(y|x) = P_Y(y)[1+f^T(x)\tilde{g}(y) + \tilde{d}(y)] \approx p_ {Y}, 同理可以得到fT(x)g̃(y)=o(ϵ),d̃(y)=o(ϵ)f^T(x)\tilde g (y) = o(\epsilon),\tilde d (y) = o(\epsilon)，我们假设对所有的f,g̃,d̃f,\tilde g,\tilde d都进行了normalize，也就是𝔼f=𝔼g̃=𝔼d̃=0\mathbb{E}f = \mathbb{E}\tilde{g} = \mathbb{E}\tilde{d} = 0,则： * 𝔼[fT(X)g̃(Y)]=∑x,ypXY(x,y)fT(x)g̃(y)=∑x,y(pX(x)pY(y)fT(x)g̃(y)+o(ϵ)fT(x)g̃(y))=∑xpX(x)fT(x)∑ypY(y)g̃(y)+o(ϵ2)=o(ϵ2). \begin{aligned} \mathbb{E}[f^T(X)\tilde g(Y) ] &= \sum_ {x,y} p_ {XY}(x,y)f^T(x)\tilde g(y)\\ &= \sum_ {x,y}(p_ {X}(x)p_ {Y}(y)f^T(x)\tilde g(y) + o(\epsilon)f^T(x)\tilde g(y))\\ &= \sum_ {x}p_ {X}(x)f^T(x) \sum_ {y}p_ {Y}(y)\tilde g(y) + o(\epsilon^2)\\ &= o(\epsilon^2). \end{aligned} * 𝔼[(fT(x)g(y))2]=∑x,ypX(x)pY(y)(fT(x)g̃(y))2+∑x,yo(ϵ)(fT(x)g̃(y))2=∑x,ypXY(x,y)(fT(x)g̃(y))2+o(ϵ3) \begin{aligned} \mathbb{E}[(f^T(x)g(y) )^2] &= \sum_ {x,y}p_ {X}(x)p_ {Y}(y)(f^T(x)\tilde g(y))^2 + \sum_ {x,y} o(\epsilon)(f^T(x)\tilde g(y))^2\\ &= \sum_ {x,y}p_ {XY}(x,y)(f^T(x)\tilde g(y))^2 + o(\epsilon^3) \end{aligned} * 𝔼[fT(x)g̃(y)d̃(y)]=∑x,ypX(x)pY(y)fT(x)g̃(y)d̃(y)+o(ϵ)∑x,yfT(x)g̃(y)d̃(y)=∑xpX(x)fT(x)∑ypY(y)g̃(y)d̃(y)+o(ϵ3)=o(ϵ3) \begin{aligned} \mathbb{E}[f^T(x) \tilde{g}(y)\tilde{d}(y)] &= \sum_ {x,y}p_ {X}(x)p_Y(y) f^T(x)\tilde g (y) \tilde d (y) + o(\epsilon)\sum_ {x,y}f^T(x)\tilde g (y) \tilde d (y)\\ &= \sum_ {x}p_ {X}(x)f^T(x) \sum_ {y}p_ {Y}(y)\tilde g(y) \tilde d(y) + o(\epsilon^3)\\ &= o(\epsilon^3) \end{aligned}

而我们知道o(ϵ3)o(\epsilon^3)在o(ϵ2)o(\epsilon^2)之前是可以被忽略的。因此最终： 𝔼[log⁡QY|X]=𝔼[log⁡pY(Y)]+𝔼[fT(X)g̃(Y)]−12𝔼[(fT(X)g̃(Y))2]−12𝔼[d2̃(y)] \mathbb{E}[\log Q_ {Y|X}] = \mathbb{E}[\log p_Y(Y)] + \mathbb{E}[f^T(X) \tilde g (Y)] - \frac 1 2 \mathbb{E}[(f^T(X) \tilde g (Y))^2] - \frac{1}{2} \mathbb{E}[\tilde{d^2} (y)]

上式中，第一项为常数，最后一项为非负值，且与前面几项没有约束关系，因此为了最大化上式只需简单令12𝔼[d2̃(y)]=0\frac{1}{2} \mathbb{E}[\tilde{d^2} (y)]=0，因此最终我们要做的是： maxf,g̃(𝔼[fT(x)g̃(y)]−12𝔼[(fT(x)g̃(y))2]⏟Δ) \max_ {f,\tilde g} (\underbrace{\mathbb{E}[f^T(x)\tilde g(y)] - \frac{1}{2}\mathbb{E} [(f^T(x)\tilde g(y))^2]}_ {\Delta})

如果我们将$ [f^T(x)g(y)] 对对f(x)$求导，可以得到： $$ \frac{\partial \Delta}{\partial f(x)} = 0\\ f(x) = \land ^{-1}_ {\tilde g (Y)} \mathbb{E}[\tilde g(Y)|X = x] $$

其中∧g̃(Y)−1=(𝔼pY[g̃(Y)g̃T(Y)])−1\land ^{-1}_ {\tilde g (Y)}=(\mathbb{E}_ {p_Y}[\tilde g(Y){\tilde g}^T(Y)])^{-1}，也就是我们得到了最佳的f,g̃f,\tilde g.

同理我们也得到： g*̃(y)=∧f(X)−1𝔼[f(X)|Y=y] \tilde {g ^*}(y) = \land ^{-1}_ {f(X)} \mathbb{E}[f(X)|Y = y]

也就是如果我们向softmax函数中喂入f(x)f(x)（形式固定）,那么softmax尽量在学的东西，也就是WW实际上是g*g^*，当然不一定能成功学到这样的形式。

同样的，利用神经网络进行softmax可以看作是在寻找Ｘ的特征，它找到的最佳形式应该是f*f*.
